# 📞 Phone Number Parser

## 📌 Description
This project is a simple C# application that parses a 10-digit phone number into its components:
- Area Code
- Central Office Code
- Line Number

It then formats the number into a standard readable format.

---

## 🚀 Features
- Validates input length (must be exactly 10 digits)
- Extracts phone number parts using string manipulation
- Formats output as: `(XXX)XXX-XXXX`
- Includes unit tests for validation

---

## 🛠 Technologies Used
- C#
- .NET
- xUnit (for testing)
